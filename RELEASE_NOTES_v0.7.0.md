# QuickSlot v0.7.0

В этой версии я сосредоточился на стабильности автоматических действий с инвентарём.

Что изменилось:
- QuickSlot теперь выполняет автоматические перестановки по одной, а не запускает несколько действий подряд;
- следующая перестановка начинается только после того, как предыдущее состояние несколько тиков остаётся правильным;
- при слишком долгом ожидании действие отменяется, а QuickSlot позже строит новый план по свежему инвентарю;
- старые действия больше не повторяются вслепую после таймаута;
- очередь сбрасывается при смене профиля, открытии контейнера, выходе из мира и респавне;
- перед выполнением QuickSlot ещё раз проверяет, что исходные слоты не изменились;
- автосортировка, Auto Refill, перенос ресурсов и объединение стеков теперь используют один общий порядок действий;
- сохранена пауза после ручной работы с инвентарём.

Версия предназначена для Minecraft 1.8.9 Forge и работает только на клиенте.
