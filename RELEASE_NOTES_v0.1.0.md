# QuickSlot v0.1.0

Первая версия QuickSlot для Minecraft 1.8.9 Forge.

Что добавлено:
- HUD с количеством железа, золота, алмазов и изумрудов;
- автоматическая раскладка хотбара;
- автоматическое пополнение назначенных слотов;
- перенос ресурсов из хотбара в основной инвентарь;
- настройка раскладки, HUD и основных параметров через конфиг.
