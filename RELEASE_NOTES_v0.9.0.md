# QuickSlot v0.9.0 RC

Эта версия — кандидат перед стабильным v1.0.0. Я не добавлял новые игровые функции, а сосредоточился на поведении QuickSlot при ручной работе с инвентарём и лаге.

Что изменилось:
- QuickSlot полностью останавливает автоматические действия, пока предмет находится на курсоре;
- после освобождения курсора выдерживается короткая защитная пауза;
- повторные таймауты действий увеличивают паузу между новыми попытками;
- задержка растёт ступенчато: 8, 16, 32 и максимум 64 тика;
- после серии успешных действий QuickSlot постепенно возвращается к обычной скорости;
- устаревшие действия по-прежнему не повторяются вслепую;
- история ошибок сбрасывается при смене мира, игрока или контейнера;
- добавлены автоматические проверки поведения защитной паузы;
- тесты запускаются вместе с обычной сборкой GitHub Actions.

Версия предназначена для Minecraft 1.8.9 Forge и работает только на клиенте.
