# QuickSlot v0.6.0

В этой версии я сделал выбор предметов более предсказуемым и добавил больше контроля над автоматической заменой снаряжения.

Что нового:
- для каждого профиля можно отдельно настроить порядок выбора блоков;
- доступны шерсть, доски, эндерняк, глина, стекло, обсидиан и остальные блоки;
- если несколько стеков относятся к одному типу, QuickSlot выбирает более крупный;
- настройку «сохранять текущий блок» теперь можно включать и выключать отдельно для каждого профиля;
- при включённой настройке QuickSlot сначала пытается продолжать использовать тот же конкретный блок;
- если нужного блока больше нет, используется обычный порядок приоритетов;
- добавлены отдельные переключатели автоулучшения меча, кирки и топора;
- при отключённом автоулучшении уже подходящий предмет остаётся в своём слоте;
- в главном меню появился новый раздел «Выбор»;
- при переключении профиля запомненный тип блока больше не переносится из предыдущего профиля.

Версия предназначена для Minecraft 1.8.9 Forge и работает только на клиенте.
