# QuickSlot v0.2.0

В этой версии я перенёс основные настройки мода прямо в игру.

Что нового:
- меню QuickSlot по клавише Right Shift;
- визуальная настройка всех 9 слотов хотбара;
- новые категории для BedWars: лук, стрелы, TNT, fireball, эндер-жемчуг, лестницы и вода;
- HUD ресурсов теперь можно перетаскивать мышкой и менять его масштаб;
- основные функции можно включать и выключать прямо из меню;
- исправлена работа раскладки, когда одна категория назначена сразу на несколько слотов;
- ресурсы теперь могут уходить из хотбара в уже существующий неполный стек, даже если свободных ячеек нет.

Настройки по-прежнему сохраняются в `quickslot.cfg` и не требуют серверной части.
