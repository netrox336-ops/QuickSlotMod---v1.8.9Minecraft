# QuickSlot

QuickSlot — небольшой клиентский мод для BedWars на Minecraft 1.8.9. Я сделал его для того, чтобы хотбар не приходилось постоянно приводить в порядок вручную во время игры.

Мод считает железо, золото, алмазы и изумруды во всём инвентаре и показывает их количество на экране. Предметы автоматически раскладываются по заданным слотам, ресурсы убираются из хотбара, а закончившиеся блоки или другие назначенные предметы подставляются из инвентаря обратно.

## Что есть в первой версии

- счётчик железа, золота, алмазов и изумрудов на экране;
- автоматическая раскладка хотбара;
- автоматическое пополнение назначенных слотов из инвентаря;
- автоматическое удаление ресурсов из хотбара;
- выбор назначения для каждого слота через конфиг;
- настройка положения и масштаба HUD.

По умолчанию раскладка такая: меч — 1 слот, блоки — 2, 3 слот пустой, золотые яблоки — 4, ножницы — 5, кирка — 6, топор — 7. Слоты 8 и 9 мод не трогает.

## Установка

1. Установите Minecraft 1.8.9.
2. Установите Forge для Minecraft 1.8.9.
3. Скачайте `QuickSlot` в формате `.jar` из раздела Releases.
4. Переместите файл в папку `.minecraft/mods`.
5. Запустите Minecraft с профилем Forge 1.8.9.

После первого запуска настройки появятся в `.minecraft/config/quickslot.cfg`.

QuickSlot работает только на клиенте. Устанавливать что-либо на сервер не нужно.
