# QuickSlot

QuickSlot — клиентский мод для BedWars на Minecraft 1.8.9. Я сделал его, чтобы во время игры не приходилось постоянно следить за ресурсами и вручную приводить хотбар в порядок.

Мод считает железо, золото, алмазы и изумруды во всём инвентаре, автоматически раскладывает предметы по заданным слотам и пополняет их из инвентаря, когда они заканчиваются. Ресурсы при желании автоматически убираются из хотбара.

## Что умеет QuickSlot

- показывает количество железа, золота, алмазов и изумрудов на экране;
- автоматически раскладывает хотбар;
- возвращает блоки и другие назначенные предметы в нужный слот;
- умеет пополнять слот только после опустошения, ниже заданного порога или постоянно держать стек заполненным;
- позволяет отдельно включать или выключать автопополнение для каждого из 9 слотов;
- умеет сохранять текущий тип блоков, если вы хотите продолжать строить тем же материалом;
- позволяет настроить приоритет блоков отдельно для каждого профиля;
- поддерживает приоритет шерсти, досок, эндерняка, глины, стекла, обсидиана и остальных блоков;
- автоматически убирает ресурсы из хотбара;
- при желании объединяет одинаковые стаки в основном инвентаре;
- делает короткую паузу после ручной работы с инвентарём, чтобы не мешать игроку;
- не запускает следующую перестановку, пока предыдущая не закрепилась в инвентаре;
- при лаге отменяет устаревшее действие вместо повторных кликов по старому состоянию;
- умеет автоматически менять меч, кирку и топор на более сильный вариант;
- автоулучшение меча, кирки и топора можно выключать отдельно;
- позволяет настроить все 9 слотов прямо в игре;
- поддерживает отдельные профили «Обычный», Rush и Bridge;
- позволяет переключать профили отдельным хоткеем прямо во время игры;
- умеет защищать выбранный игроком слот, чтобы QuickSlot не переставлял предмет прямо из руки;
- показывает компактный статус с активным профилем и состоянием автосортировки;
- поддерживает меч, блоки, золотые яблоки, ножницы, кирку, топор, лук, стрелы, TNT, fireball, эндер-жемчуг, лестницы и воду;
- позволяет перетаскивать HUD и менять его масштаб.

## Настройки

Нажмите **Right Shift** в игре, чтобы открыть меню QuickSlot. Клавишу можно поменять в обычных настройках управления Minecraft.

По умолчанию клавиша **V** переключает активный профиль по кругу: «Обычный» → Rush → Bridge → «Обычный». Её тоже можно изменить в настройках управления Minecraft.

В меню можно включить или выключить автосортировку, перенос ресурсов, защиту выбранного слота, счётчик ресурсов и HUD состояния. Там же настраиваются раскладка хотбара, профили, автоматическое пополнение, положение HUD и его масштаб.

В разделе **«Пополнение»** можно отдельно отключить Auto Refill для любого слота текущего профиля. В разделе **«Инвентарь»** находятся объединение одинаковых стеков и пауза после ручной работы с инвентарём.

В разделе **«Выбор»** настраивается поведение QuickSlot, когда подходит сразу несколько предметов: можно включить сохранение текущего блока, изменить порядок блоков и отдельно отключить автоматическое улучшение меча, кирки или топора.

Текущая пользовательская раскладка из предыдущих версий сохраняется в профиле «Обычный».

## Установка

1. Установите Minecraft 1.8.9.
2. Установите Forge для Minecraft 1.8.9.
3. Скачайте `.jar` QuickSlot из раздела Releases.
4. Переместите файл в `.minecraft/mods`.
5. Запустите Minecraft через Forge 1.8.9.

QuickSlot работает только на клиенте. На сервер ничего устанавливать не нужно.
