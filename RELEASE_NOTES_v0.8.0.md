# QuickSlot v0.8.0

В этой версии я довёл Auto Refill до нормальной послотовой настройки и упростил работу с профилями.

Что нового:
- для каждого слота каждого профиля теперь отдельно сохраняются включение Auto Refill, режим и порог;
- один слот может работать только после опустошения, другой — пополняться ниже заданного количества, а третий — постоянно держать максимум;
- старые общий режим и порог автоматически переносятся как стартовые значения, поэтому настройки после обновления не пропадают;
- экран «Пополнение» переделан под настройку выбранного слота;
- настройки активного профиля можно скопировать в другой профиль;
- при копировании переносятся раскладка хотбара, Auto Refill и настройки выбора блоков;
- глобальные настройки HUD, инвентаря и снаряжения при копировании не меняются;
- добавлен полный сброс активного профиля с отдельным подтверждением;
- сброс одного профиля не затрагивает остальные профили и глобальные параметры.

Версия предназначена для Minecraft 1.8.9 Forge и работает только на клиенте.
