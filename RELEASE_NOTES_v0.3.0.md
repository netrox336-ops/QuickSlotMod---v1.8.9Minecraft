# QuickSlot v0.3.0

В этой версии я добавил профили хотбара и сделал автоматическое пополнение заметно гибче.

Что нового:
- три профиля раскладки: «Обычный», Rush и Bridge;
- отдельный экран выбора профиля;
- каждый профиль хранит свою раскладку 9 слотов;
- старая пользовательская раскладка автоматически переносится в профиль «Обычный»;
- три режима Auto Refill: только когда слот пуст, ниже заданного порога и постоянное заполнение;
- порог пополнения настраивается прямо в игре;
- QuickSlot запоминает последний тип блоков в слоте и старается пополнять именно его;
- если нужных блоков больше нет, используется самый большой подходящий стек;
- главное меню теперь показывает активный профиль.

Версия предназначена для Minecraft 1.8.9 Forge и работает только на клиенте.
