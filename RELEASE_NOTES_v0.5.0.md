# QuickSlot v0.5.0

В этой версии я доработал автоматическое пополнение и сделал работу с инвентарём спокойнее.

Что нового:
- Auto Refill теперь можно включать и выключать отдельно для каждого из 9 слотов;
- настройки refill сохраняются отдельно для профилей «Обычный», Rush и Bridge;
- если refill для слота выключен, QuickSlot не заполняет пустой слот и не дозаполняет неполный стек;
- добавлено объединение одинаковых стеков в основном инвентаре;
- объединение стеков можно выключить отдельно от автосортировки;
- хотбар при объединении стеков не затрагивается;
- после закрытия инвентаря QuickSlot делает короткую паузу перед возобновлением автоматических действий;
- добавлен отдельный раздел «Инвентарь» в настройках;
- экран настройки пополнения обновлён под новые переключатели слотов.

Версия предназначена для Minecraft 1.8.9 Forge и работает только на клиенте.
